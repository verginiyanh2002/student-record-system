# Student Record System

A console application written in C# for CSP3341 (Programming Languages and Paradigms).
It stores student records (ID, name, course, status and WAM), lets you add, view,
delete and search students, shows statistics, and saves the records to a CSV file.

## How to run
1. Install the .NET SDK (version 10).
2. Open a terminal in this folder.
3. Run: dotnet run
